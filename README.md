# Мыс Баранова: абсолютные измерения МПЗ

Открытая страница с графиками и таблицей абсолютных и базисных значений магнитной станции «Ледовая база Мыс Баранова» (ААНИИ). Данные берутся из ежемесячных отчётов станции (`.docx`).

## Как устроено

```
reports/                 ежемесячные отчёты .docx (имя файла не важно, месяц берётся из текста «ЗА <МЕСЯЦ> <ГОД> Г.»)
parse.py                 читает все отчёты → site/data.json, site/data.csv, site/check_report.txt
site/index.html          сама страница (Plotly.js, без сервера и без базы данных)
.github/workflows/       автосборка: при каждом изменении запускает parse.py и публикует site/ на GitHub Pages
```

## Как добавить новый отчёт

1. Откройте репозиторий на GitHub → папка `reports` → **Add file → Upload files**.
2. Перетащите новый `.docx` и нажмите **Commit changes**.
3. Через 1–2 минуты сайт обновится. Ход сборки и список замечаний к данным видны на вкладке **Actions** (последний запуск → Summary).

Если отчёт за этот месяц уже есть, новый файл с тем же месяцем будет пропущен как дубликат. Чтобы заменить отчёт, удалите старый файл или загрузите новый под тем же именем.

## Что проверяет parse.py

- месяц и год каждой даты совпадают с заголовком отчёта (опечатки в годе исправляются и помечаются);
- T = √(H² + Z²) и I = arctg(Z/H) для абсолютных значений;
- среднее и СКО в отчёте совпадают с пересчётом по строкам таблицы (СКО по n−1);
- в ячейках стоят числа, а не текст;
- нет повторных отчётов и повторных измерений.

Замечания не останавливают сборку: строки с замечаниями подсвечиваются на сайте, а полный список выводится в блоке «Проверка данных».

## Запуск у себя

```bash
pip install -r requirements.txt
python3 parse.py reports site
cd site && python3 -m http.server 8000     # открыть http://localhost:8000
```

Сайт можно разместить на любом веб-сервере (например, на сервере ААНИИ): достаточно скопировать содержимое папки `site/` после запуска `parse.py`.
